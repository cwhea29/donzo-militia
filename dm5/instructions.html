🚀 Getting Started

The Donzo Militia map is a live, synced database of GTA V locations across Los Santos and Cayo Perico. Markers are stored in the cloud and update in real-time — when a Lieutenant or Commander adds a location, it appears instantly for everyone with the right clearance level, on any device.

  1. 1
    Log in at the main page using your callsign and password. New? Ask a Commander to add you via the Users panel.
  2. 2
    Select your zone — Los Santos (mainland) or ☠ Cayo Perico. Each zone has its own separate markers.
  3. 3
    Choose a map layer — Atlas for overview, Roadmap for streets, or Satellite for terrain.
  4. 4
    Click any marker on the map to view its details. Locations hidden from your access level are completely invisible.

🔐 Access Levels

A four-tier system controls what each member can see and do. Lower-level members can't even see locations that are above their clearance — the markers are completely invisible to them.

Level 1 — Recruit
Sees Public locations only. Cannot place or delete markers.
Level 2 — Operative
Sees Public + Restricted. Cannot place markers yet.
Level 3 — Lieutenant
Sees Public + Restricted + Confidential. Can place markers and delete their own.
Level 4 — Commander
Full access to all locations including Top Secret. Can place/delete any marker and manage all users.

➕ Adding a Location (Level 3+)
  1. 1
    Click 📍 Place Marker in the controls bar. Your cursor changes to a crosshair.
  2. 2
    Click anywhere on the map where you want to drop the pin. A form opens.
  3. 3
    Fill in the name (required), optional description, optional photo upload, category, and the minimum access level to view this location.
  4. 4
    Click Save Location. It appears instantly for all users with the right clearance — no refresh needed.
🖼️
Images: When adding a marker you can upload a photo directly — it is stored securely in Supabase Storage and delivered via CDN. No manual file placement needed.
⛔
Think before setting visibility. Once saved, only a Commander can delete it. If you get the level wrong, ask a Commander to delete and re-add it.
👥 User Management (Level 4 Only)

Commanders access the 👥 Users button in the controls bar to add new members, change access levels, or remove users who have left the org. You can also add users directly in the Supabase dashboard under Table Editor → users.

⛔
SECURITY NOTE — Passwords are stored in plain text in the Supabase users table. This is a known limitation of the current demo auth system. Use unique strong passwords. For any real operational use, migrate to proper Supabase Auth + Row Level Security + hashed passwords. Never reuse passwords from other sites.
