🚀 Getting Started

The Donzo map is a live, synced database of GTA V locations across Los Santos and Cayo Perico. Markers are stored in the cloud and update in real-time — when authorized members add a location, it appears instantly for everyone with the right clearance level, on any device.

  1. 1
    Log in at the main page using your callsign and password. New? Ask a Commander to add you via the Users panel.
  2. 2
    Select your zone — Los Santos (mainland) or ☠ Cayo Perico. Each zone has its own separate markers.
  3. 3
    Choose a map layer — Atlas for overview, Roadmap for streets, or Satellite for terrain.
  4. 4
    Click any marker on the map to view its details, add comments, or (if authorized) edit/delete. Locations hidden from your access level are completely invisible.

Switching layers does not move or remove markers. All locations stay pinned exactly where they were placed. If your custom map images are missing you will see a high-quality stylized fallback (markers still fully functional).
🔐 Access Levels

An 11-tier hierarchy controls what each member can see and do. Lower-level members can't even see locations that are above their clearance — the markers are completely invisible to them.

Level 1 — Hangy
Barely sees anything. Very limited visibility.
Level 2 — Cadet
Sees basic public locations only.
Level 3 — Private
Sees more than Cadets. Still very restricted.
Level 4 — Gunner
Can place markers. Sees mid-level locations.
Level 5 — Corporal
Can place and delete their own markers.
Level 6 — Commander
Solid mid-high access. Can manage some locations.
Level 7 — Captain
High clearance. Can see most sensitive locations.
Level 8 — Chief
Can delete most markers.
Level 9 — Warboss
Near top tier. Very high access.
Level 10 — Underboss
Extremely high clearance.
Level 11 — Boss
Full admin access. Sees everything. Can place and delete any marker + manage users.

🗂️ Groups, Comments & Heist Plans

Groups: Tag locations with arbitrary labels ("Casino", "Stores", "Cayo Runs"). Use the sidebar filters or the checkboxes when placing/editing a marker. Create new groups from the Locations sidebar.

Comments: Every location popup has a live comment thread. Only the original poster can edit or delete their comments. Great for updates ("heat high", "new cameras", "cleared").

Heist Plans: Build ordered sequences of markers (steps). Open from the Locations sidebar. Add/remove/reorder steps. Perfect for multi-stage operations. Plans are org-wide.

➕ Adding a Location (Gunner / Level 4+)
  1. 1
    Click 📍 Place Marker in the controls bar. Your cursor changes to a crosshair.
  2. 2
    Click anywhere on the map where you want to drop the pin. A form opens.
  3. 3
    Fill in the name (required), optional description, optional photo upload, category, and the minimum access level required to view this location (up to Boss only).
  4. 4
    Click Save Location. It appears instantly for all users with the right clearance — no refresh needed.
🖼️
Images: When adding a marker you can upload a photo directly — it is stored securely in Supabase Storage and delivered via CDN. No manual file placement needed. Groups let you tag locations (e.g. "Bank Jobs") for quick filtering.
⛔
Think before setting visibility. Once saved, only a Commander can delete it. If you get the level wrong, ask a Commander to delete and re-add it.
👥 User Management (Level 4+ — Commanders and above)

Commanders (and higher) access the 👥 Users button in the controls bar to add new members, change access levels, or remove users who have left the org. You can also add users directly in the Supabase dashboard under Table Editor → users.

⛔
SECURITY NOTE — Passwords are stored in plain text in the Supabase users table. The Supabase anon key is public in the client. Anyone who inspects the page can read/write data within their access level. Use unique strong passwords you do not use elsewhere. This is an internal tool — for production use, replace with proper Supabase Auth (email/pw + JWT), enable RLS policies on all tables, and move user creation to server-side or edge functions. Audit log everything.
